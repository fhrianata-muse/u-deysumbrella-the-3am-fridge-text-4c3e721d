Entry for the make.fun bounty
[The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d)
by [@expylar](https://make.fun).

`main.py` writes one 3am text message from a smart fridge to its owner
to `/output/entry.txt` (1–140 characters, one line, no trailing newline).
Run it with `python3 main.py`. No network, no input files, no arguments;
two runs write byte-identical output.
